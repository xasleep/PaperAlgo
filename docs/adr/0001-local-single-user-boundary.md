# ADR 0001：本地单用户部署边界

- 状态：已接受
- 日期：2026-07-14

## 背景

本项目是个人在 Windows 工作站上运行的论文到代码 Agent。FastAPI 控制 `codes/run_pipeline.py` 子进程，任务产物和模型配置保存在本机。当前系统没有账户、认证、授权或多租户隔离。

## 决策

- 服务只按 `127.0.0.1` 本地回环地址部署，不把当前实现描述为公网或局域网安全服务。
- 使用单个 FastAPI 实例服务一个本地用户。
- 本地 Vite 开发仅允许 `http://localhost:5173` 和 `http://127.0.0.1:5173` 跨域访问；CORS 不作为认证机制。
- 不在本基线中引入反向代理、账户系统、OAuth、远程队列或多租户能力。
- `.local/` 和运行目录可能含敏感材料，必须保持在版本管理之外。

## 后果

开发和故障排查保持简单，但用户不得使用 `--host 0.0.0.0` 将服务直接暴露到其他机器。若未来需要远程或多用户访问，必须新增独立 ADR 和威胁模型，不能沿用本地边界声明。
